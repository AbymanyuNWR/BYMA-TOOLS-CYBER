## 🚀 Usage

### 🔐 Interactive Mode (Recommended for Beginners)

```bash
# Start interactive mode with login
python main.py --interactive
# or
python main.py -i
```

**Interactive Flow:**
1. **Register** - Create your account (first time)
2. **Login** - Enter your credentials
3. **Main Menu** - Choose a tool category
4. **Sub Menu** - Select specific tool
5. **Input** - Enter target/parameters
6. **Results** - View scan results
7. **Continue** - Choose to continue, go back, or exit

### 💻 Command Line Mode (Direct Execution)

```bash
# Basic syntax
python main.py <command> [options]

# Examples
python main.py recon subdomain example.com
python main.py scan vuln http://target.com
python main.py stats
```

### Show Help

```bash
# Main help
python main.py --help

# Module-specific help
python main.py recon --help
python main.py scan --help
```

## 💡 Examples

### 🔍 Reconnaissance

```bash
# Subdomain enumeration
python main.py recon subdomain example.com

# Port scanning
python main.py recon port 192.168.1.1 --ports 1-1000

# WHOIS lookup
python main.py recon whois example.com

# DNS records
python main.py recon dns example.com

# IP geolocation
python main.py recon ip 8.8.8.8

# Email harvesting
python main.py recon email example.com

# Technology detection
python main.py recon tech http://example.com
```

### 🛡️ Vulnerability Scanning

```bash
# SQL injection test
python main.py scan sqli "http://target.com/?id=1"

# XSS test
python main.py scan xss "http://target.com/search?q=test"

# Directory bruteforce
python main.py scan dir http://target.com

# SSL/TLS check
python main.py scan ssl target.com

# WAF detection
python main.py waf http://target.com
```

### 🌐 Network Tools

```bash
# Network scan (ARP discovery)
python main.py network scan 192.168.1.0/24

# Port scan
python main.py network port 192.168.1.1 --ports 1-1024

# Packet sniffing (requires admin/root)
sudo python main.py network sniff

# ARP spoofing (requires admin/root)
sudo python main.py network arp --target 192.168.1.100 --gateway 192.168.1.1
```

### 🔑 Password Tools

```bash
# Generate hash
python main.py password hash "password123"

# Generate secure password
python main.py password generate --length 16 --count 10

# Crack hash (requires wordlist)
python main.py password crack <hash_file> md5 --wordlist passwords.txt
```

### 🕸️ Web Analysis

```bash
# Crawl website
python main.py web crawl http://example.com

# Analyze HTTP headers
python main.py web headers http://example.com

# Scrape proxies
python main.py web proxy
```

### 💥 Exploit Tools

```bash
# Generate reverse shell
python main.py exploit reverse 192.168.1.100 4444 --type python

# Generate webshell
python main.py exploit webshell --type php

# Credential harvesting
python main.py credential http://target.com
```

### 🔬 Forensics

```bash
# Analyze file
python main.py forensics analyze suspicious.exe

# Extract strings
python main.py forensics strings malware.bin

# Check file hash
python main.py forensics hash suspicious.exe
```

### 🤖 Auto Scan

```bash
# Smart auto-scan
python main.py auto http://target.com

# Aggressive mode
python main.py auto http://target.com --mode aggressive
```

### 📊 Reports

```bash
# Generate HTML report
python main.py report

# Report for specific scan
python main.py report --scan-id 1
```

### 🔌 Plugins

```bash
# List available plugins
python main.py plugin --list

# Create new plugin
python main.py plugin --create myplugin

# Run plugin
python main.py plugin --run myplugin
```

### 🌐 API Server

```bash
# Start REST API server
python main.py api --port 8080

# Access API documentation
# http://localhost:8080/docs
```

### 📈 Database

```bash
# View statistics
python main.py stats

# View scan history
python main.py history

# Clear database
python main.py clear
```

## 🔌 Plugin System

### Create Custom Plugin

```bash
python main.py plugin --create my_scanner
```

This creates a template in `plugins/my_scanner.py`:

```python
from core.colors import *

class Plugin:
    def __init__(self):
        self.name = "My Scanner"
        self.version = "1.0"
    
    def run(self, target):
        print(f"Running scan on {target}")
        # Your code here
        return results
```

### Run Plugin

```bash
python main.py plugin --run my_scanner
```

## 🛡️ Stealth Mode

Use stealth mode to avoid detection:

```bash
# Stealth scan
python main.py stealth --scan 192.168.1.1

# Decoy scan (use fake IPs)
python main.py stealth --scan 192.168.1.1 --decoy

# Slow scan (avoid rate limiting)
python main.py stealth --scan 192.168.1.1 --slow
```
